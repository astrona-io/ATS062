# Understand Argo Rollouts Fundamentals

This section covers understand Argo Rollouts Fundamentals. It develops rollout Controller, ReplicaSets And Promotion State through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains include an intermediate checkpoint before the final review.

## Learning Outcomes

- Distinguish a Rollout resource from a standard Deployment.
- Explain controller-managed versions and strategy state.
- Separate readiness, promotion and analysis evidence.
- Evaluate service integration, ownership and rollback limits.
